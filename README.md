# Data Correlation Analysis & Data Transposition

## 🎯 Project Goal
Advanced data manipulation using **Pandas**, including statistical correlation analysis and spatial/structural data transposition.

## 📊 Overview & Modules

### 1. Global Educational Data — Correlation & Transposition
- **Dataset:** [World Educational Data](https://www.kaggle.com/datasets/nelgiriyewithana/world-educational-data) (Kaggle)
- **Key Techniques:** Calculation of **Pearson correlation coefficients** between key educational indicators; reshaping and transposing DataFrames for structured analysis.

### 2. Robot Kinematics — Data Filtering & Percentiles
- **Dataset:** [Robot Kinematics Dataset](https://www.kaggle.com/datasets/sandibaressiegota/robot-kinematics-dataset) (Kaggle)
- **Key Techniques:** Advanced row filtering based on statistical thresholds and percentiles (e.g., isolating data below the 25th percentile for specific variables).

## 🧰 Tech Stack
`Python` `Pandas` `NumPy`
